# MedQuery AI

### Evidence-Grounded Medical Question Answering
### Using Hybrid Retrieval-Augmented Generation

MedQuery AI is an academic AI research and development
project designed to provide evidence-grounded answers
to medical questions using Retrieval-Augmented Generation.

## Core Objectives

- Retrieve relevant medical information.
- Implement hybrid information retrieval.
- Improve retrieval through reranking.
- Generate evidence-grounded responses.
- Provide source-level citations.
- Evaluate answer quality and faithfulness.
- Implement safety-aware response mechanisms.

## Technology Stack

- Python
- FastAPI
- Streamlit
- Sentence Transformers
- ChromaDB
- BM25
- Large Language Models

## Project Status

Under Development.
